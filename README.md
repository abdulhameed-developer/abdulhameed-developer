# Abdul Hameed

I’m a WordPress developer at DE Media Solutions Pvt. Ltd. in Lahore, Pakistan. I build custom plugins, themes and searchable directories with PHP, MySQL and the WordPress REST API.

## Selected projects

- [Course Comparator Pro](https://github.com/abdulhameed-developer/course-comparator-pro) maps JetEngine taxonomy metadata into course comparisons and generates PDFs on the server.
- [Consultation Booking Pro](https://github.com/abdulhameed-developer/consultation-booking-pro) connects a WordPress booking workflow to Google Calendar.
- [My Secure Plugin](https://github.com/abdulhameed-developer/my-secure-plugin) is a small PHP plugin skeleton with a settings page and a shortcode.
